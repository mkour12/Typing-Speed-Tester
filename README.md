
# Typing Speed Tester

A console-based typing speed testing application developed using Core Java.

## Features
- Three difficulty levels: Easy, Medium and Hard
- Calculates typing speed in Words Per Minute (WPM)
- Calculates typing accuracy
- Maintains test history
- Saves results using file handling

## Technologies Used
- Java
- Object-Oriented Programming
- Java Collections Framework
- Exception Handling
- Java File I/O

## Concepts Demonstrated
- Classes and Objects
- Abstraction and Inheritance
- Method Overriding
- Encapsulation
- ArrayList
- Exception Handling
- BufferedReader and BufferedWriter

## How to Run

Compile:
```bash
javac -d out src/*.java
```

Run:
```bash
java -cp out TypingSpeedTester
```
